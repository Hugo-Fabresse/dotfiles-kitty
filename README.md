# dotfiles-kitty

Kitty terminal configuration.
Black, dense, no decoration.

---

## Stack

- **Terminal** : Kitty
- **Shell** : Zsh
- **Font** : Maple Mono NF Bold

---

## Dependencies

```bash
sudo pacman -S kitty
yay -S maplemono-otf
```

---

## Install

```bash
git clone git@github.com:Hugo-Fabresse/dotfiles-kitty.git ~/dotfiles/kitty
ln -s ~/dotfiles/kitty ~/.config/kitty
```
